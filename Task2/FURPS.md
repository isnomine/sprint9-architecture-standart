| S2  | Внедрение нового функционала возможно, но чтобы они были совместимы с существующими платформами разработки |                                                                                                                          |
| S3  | Разработка документации                                                                                    |                                                                                                                          |
| S4  | Возможность масштабирования и доработки системы в будущем                                                  |                                                                                                                          |
