### <a name="_qmphm5d6rvi3"></a>**Решение**

* Разработка сервиса обработк депозитов на .Net
* Использование брокера kafka для общения интернет банка с новым сервисом

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1) Покупка вендорского решения
2) Использование других технологий для разработки (например java)
3) Использование синхронных запросов между сервисами вместо брокера
4) Использование вместо kafka других технологий, например RabbitMQ или Кувшы

**Недостатки, ограничения, риски**

1. Возможны проблемы при интеграции файлов xls и системы ABS. разработка сервиса для автоматизации может затянуться или быть слишком сложной
2. АБС не масштабируется горизонтально, нужна серьезная доработка
3. Использование новых технологий типа kafka, .Net Core могут потребовать дополнительного времени на обучение команды
4. Требуется дополнительная безопасность для защиты данных, передаваемых через интернет-каналы.
