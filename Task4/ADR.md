* Использование брокера kafka для общения интернет банка с новым сервисом

### <a name="_bjrr7veeh80c"></a>**Альтернативы**
1) Передача файлов по почте
2) Передача файлов по scp
3) Передача файлов через облачное хранилище

**Недостатки, ограничения, риски**

1. Необходимо шифрование данных при передаче
2. Необходимо проработать идентификацию клиентов
3. Сетевые проблемы могут помешать актуализировать информацию по депозитам для партнеров
